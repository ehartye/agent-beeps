# Touch

An eight-bar, 92 BPM expression study: FM lead over electric keys, sine bass and light percussion.
Velocity shapes the lead's filter, FM index and attack. Note-local curves add small scoops,
delayed vibrato and brightness gestures.

[Hear the matched A/B comparison](https://ehartye.github.io/agent-beeps/#touch).
Both takes use the same notes, velocities and arrangement. The plain take removes only the lead's
curves and velocity mapping. Source and reproduction notes are in [the booth](../../../showcase/README.md#touch-an-expression-study).

```sh
beeps song check touch
beeps song render touch
```
