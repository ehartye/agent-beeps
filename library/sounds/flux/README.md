# Flux

Three controlled FM studies: Alloy, Arc and Pulse core. Each static/shaped pair uses the same
oscillators, frequencies, amp, layers and effects. The shaped recipe adds a normalized index
envelope to the modulator. Source-level spectral motion is the comparison; preference is for
owner listening. These are examples, with no owner kit/taste approval recorded.

[Play the live comparison](https://ehartye.github.io/agent-beeps/#flux). Playback uses seeds 73,
307 and 1109 respectively and the showcase project scale. Matched delivery trims and measured
levels are in [flux-quality.json](../../../showcase/media/flux-quality.json).

Edit `scripts/compose-flux.mjs`, then run `npm run showcase:compose` and `npm run showcase:render`
to reproduce the library/public recipes and measurements.
